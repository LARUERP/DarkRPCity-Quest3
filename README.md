# DarkRPCity Quest 3

Reconstruction de la ville DarkRPCity pour un futur portage BONELAB Quest 3.

## Projet
- Unity d'origine : 2021.3.16f1
- Ressources : archive DarkRPCity_RECONSTRUCTION.zip
- Objectif : reconstruire la scène, ses bâtiments, ses matériaux et ses niveaux de détail.
- Cible : Meta Quest 3 standalone.

## Important
Les ressources exportées ne constituent pas encore une carte jouable.
L'importation, la reconstruction de la scène et l'optimisation Quest 3 restent à effectuer.
